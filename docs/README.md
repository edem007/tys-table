# Ty's Table — Screenshots

Place your screenshots here for the README badges and portfolio presentation.

## Required Screenshots

| File | Description |
|------|-------------|
| `hero.png` | Full-page screenshot of the homepage / main dashboard |
| `dashboard.png` | Dashboard with a savings goal in progress (progress bar visible) |
| `ai-suggestion.png` | The AI strategist card showing a cook or dine-out recommendation |
| `celebration.png` | The confetti celebration overlay when a goal is reached |
| `onboarding.png` | The first-run onboarding wizard |

## How to Take Screenshots

1. Open the live app at your Vercel URL
2. Use your browser's built-in screenshot tool or a browser extension
3. Recommended size: **1200 × 800px** (desktop) or **390 × 844px** (iPhone 14 Pro)
4. Save as PNG in this `docs/` folder
5. Commit and push — the README will auto-display them

## Tips for Good Portfolio Screenshots

- Use **real data** (not empty state) — a goal at ~50% looks best
- For the celebration screenshot: reach $120 and hit "Cash Out"
- For the AI suggestion: open the app around 6 PM when the daily pick is fresh
- Dark theme or light? The app uses warm parchment — looks great on light backgrounds
