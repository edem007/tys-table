# Ty's Table

**Turn home cooking into dining experiences.** Ty's Table is an AI-powered savings app that banks money every time you cook at home — then helps you spend it on unforgettable nights out in Dallas (and your city).

## What It Does

Every night you cook instead of going out, Ty's Table banks **$16** toward a savings goal — like a $120 Bishop Arts dinner or a $200 Michelin-starred night. When you're ready to splurge, your AI strategist (powered by Claude) tells you exactly where to go, what to order, and how far your savings stretch.

### Core Features

- **Cook → Save:** Log cook nights instantly. Each one banks $16 toward your active goal.
- **AI Strategist:** Claude analyzes your balance, cuisine preferences, and local scene to suggest tonight's perfect move — cook a recipe that saves you $28, or dine out at exactly the right spot.
- **Daily Pick:** Fresh AI suggestion every evening at 6 PM (Dallas time), auto-generated by Vercel Cron.
- **This Week in Dallas:** AI-curated local dining events, pop-ups, and openings pulled via real-time web search.
- **Weekly Brief:** Sunday digest of your savings progress + what's happening in the Dallas food scene.
- **Savings Goals:** Name your goal (e.g. "Nobu Date Night"), set a target, watch the progress bar fill.
- **Cash Out:** Reached your goal? Lock it in. The celebration animation fires and a new goal begins.

## Getting Started

### Prerequisites

- Node.js 20+
- [Upstash](https://upstash.com) Redis database (free tier works)
- [Anthropic](https://console.anthropic.com) API key

### Installation

```bash
git clone https://github.com/edem007/tys-table.git
cd tys-table
npm install
```

Copy the environment template and fill in your values:

```bash
cp .env.example .env.local
```

```bash
# .env.local — fill in your real values
UPSTASH_REDIS_REST_URL=your_upstash_url
UPSTASH_REDIS_REST_TOKEN=your_upstash_token
ANTHROPIC_API_KEY=your_anthropic_key
CRON_SECRET=your_random_secret   # optional, protects the cron endpoint
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## How the AI Works

Every suggestion is generated by Claude with full context:

```
Balance: $64 / $120 · Fund: Bishop Arts Dinner
Ty's tastes: soul food, Italian, African cuisines.
Loves lounge culture, intimate vibes, unique experiences — not chains.
Monthly dining budget ~$400, planning 4 cook nights and 3 dine-out nights/week.
```

Claude returns structured JSON with a `cook` or `dine_out` recommendation, estimated cost, reasoning, and a home alternative. The **Dallas feed** uses Claude's built-in web search tool to find real current events — no third-party events API needed.

## Deployment

This app is designed for **Vercel**. After connecting your GitHub repo:

1. Add all environment variables from `.env.example` in Vercel's dashboard
2. The cron job (`vercel.json`) fires automatically at `0 23 * * *` UTC (6 PM CDT)
3. Every deploy is serverless — no servers to manage
